# Açık skill'ler

Claude Code (ve SKILL.md destekleyen diğer araçlar) için paylaşılan skill'ler.

## Kurulum

Skill klasörünü `~/.claude/skills/` altına kopyala:

```bash
git clone https://github.com/zaferyildiz12/skills.git
cp -r skills/musteri-cevap-gelistir ~/.claude/skills/
```

## Skill'ler

- **musteri-cevap-gelistir**: Müşteriye yazılan taslak cevabı, tonu ve kararları koruyarak netleştirir; GA4, GTM, Consent Mode gibi teknik bağlamı doğru şekilde ekler.
